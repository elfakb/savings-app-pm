# Problem Statement

Young individuals aged 18-27 — regardless of whether their income is
stable or irregular — want to build savings for financial security.
However, existing financial tools are complex, fail to build trust, and
don't adapt to different income patterns. This results in savings
behavior that either never starts or isn't sustained.


# How Might We (HMW)

## For Persona 1 — Mert (Fixed Income)
1. HMW help users see where their money goes instantly, without complex analysis?
2. HMW present investment/fund options in a trustworthy way, without financial jargon?
3. HMW break the "I'll start next month" postponement cycle and prompt action now?
4. HMW help users set a concrete, personal goal and keep it visible?

## For Persona 2 — Ece (Irregular Income)
1. HMW create an automatic but income-sensitive (proportional, not fixed) saving mechanism?
2. HMW reduce the panic users feel during low-income months?
3. HMW show that even small/variable amounts contribute meaningfully to progress?
4. HMW help users break abstract goals (like "emergency fund") into concrete, reachable steps?
