# Jobs To Be Done (JTBD)

Format: "When [situation], I want to [motivation], so I can [expected outcome]."

## JTBD 1 — Visibility
When I spend my paycheck, I want to clearly see where my money goes,
so I can avoid being surprised or regretful at the end of the month.

## JTBD 2 — Trust / Complexity
When I decide to save or invest, I want to understand the process and
risk in simple terms, so I don't fear making the wrong decision.

## JTBD 3 — Meaninglessness
When I have a small amount of money left, I want to see that it still
makes a difference, so I don't give up thinking "it won't matter anyway."

## JTBD 4 — Sustainability
When I try to build a saving habit, I want a system that survives
setbacks (emergencies, low motivation), so my earlier effort isn't wasted.

## JTBD 5 — Irregular Income
When my income changes month to month, I want a flexible saving method,
so I don't feel excluded by systems built for fixed salaries.

## JTBD 6 — Goal Ambiguity
When I start saving, I want a concrete goal to work toward, so I don't
lose motivation from not knowing "why" I'm doing it.
