# User Flow — Savings App (First-Time Use)

[Start] Open App
    ↓
[Screen 1] Welcome / Onboarding
    ↓
[Screen 2] Income Type Selection (Fixed vs Variable)
    → Fixed → Screen 3A
    → Variable → Screen 3B
    ↓
[Screen 3A] Fixed Income — Method Selection (Round-Up / Percentage)
    ↓
[Screen 3B] Variable Income — Method Selection (Percentage only recommended)
    ↓
[Screen 4] Goal Setting (Emergency Fund / Vacation / Device / Open Savings)
    ↓
[Screen 5] Confirmation Screen (summary of choices)
    ↓
[Screen 6] Main Dashboard
    - Visual progress bar
    - "Days covered" security score
    - Recent activity feed
    ↓
[Branch] Low-Income Month Detected
    ↓
[Screen 7] Notification: "Your income looks low this month"
    → Panic Button offered
    ↓
[Screen 8] Panic Button Confirmation — auto-saving paused temporarily
    ↓
[Back to Screen 6] Dashboard (state updated)

## Key Decision Points
- Screen 2: Income type branch — where Persona 1 and Persona 2 paths diverge.
- Screens 7-8: Panic Button — directly addresses Ece's core pain point.
- Screen 6: Dashboard — central hub solving both visibility and motivation gaps.
