# Usability Test Findings & Iteration

## Key Findings (Simulated)
1. Users understood the Round-Up concept quickly, but the Percentage
   method needed clearer wording ("percentage of what, exactly?").
2. The "days covered" score was well received — participants said it
   made saving feel more concrete than a plain currency amount.
3. Some participants missed the Panic Button notification because it
   looked too similar to a standard alert.
4. Goal selection screen was clear, but the optional "target amount"
   field was often skipped or misunderstood.

## Iterations Made
1. **Percentage method:** Added a one-line clarifying example directly
   on Screen 3A ("e.g. 10% of $500 income = $50 saved").
2. **Panic Button notification:** Increased visual weight (border,
   distinct color) on Screen 7 to separate it from routine notifications.
3. **Goal target amount:** Added a short helper text: "You can skip this
   and set it later."

## Before / After
- Before: Generic alert style for Screen 7 → After: Distinct, higher-
  contrast alert style specifically for financial flexibility moments.
- Before: No example on percentage screen → After: Inline example added.
