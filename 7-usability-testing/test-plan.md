# Usability Test Plan (Simulated)

Note: This is a simulated test plan created for portfolio purposes,
following standard usability testing methodology.

## Objective
Validate whether the core flow (goal setting → saving method selection →
dashboard understanding → panic button usage) is intuitive for both
fixed-income and irregular-income users.

## Participants
5 participants (3 fixed-income profile, 2 irregular-income profile),
matching Persona 1 and Persona 2 characteristics.

## Tasks
1. Set up a savings goal from scratch (Screens 1-5).
2. Locate and interpret the "days covered" score on the dashboard.
3. Simulate a low-income month and use the Panic Button.

## Metrics Tracked
- Task completion rate
- Time on task
- Points of confusion / hesitation
- Post-task satisfaction (1-5 scale)

## Success Criteria
- 4/5 participants complete all 3 tasks without assistance.
- No critical confusion during the Panic Button flow (this is the most
  novel and untested concept).
